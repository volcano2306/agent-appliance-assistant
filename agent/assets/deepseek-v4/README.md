Unmodified official DeepSeek V4 text tokenizer, MIT license preserved alongside.
Loaded locally by `tokenizers`; no remote code, model weights, downloads or dotenv.
Counts canonical JSON/text, not the provider's hidden chat template. `exactCount=false`;
actual API usage is authoritative for billing. Deployments using another tokenizer
must supply a compatible counter and change the policy before enabling compression.
